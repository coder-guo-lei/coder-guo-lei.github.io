工厂生产监控大屏

项目介绍

工厂生产监控大屏是一套面向制造企业的数字化生产监控平台，主要用于实时展示工厂设备运行状态、生产数据、告警信息、能耗统计与生产进度等核心业务数据，帮助管理人员快速掌握生产动态。

应用技术：Vue2 Vuex Vue Router ECharts DataV WebSocket Element UI Axios SCSS

我的职责

数据可视化

  • 使用 ECharts + DataV 实现生产数据可视化
  • 包括设备运行状态、能耗分析、设备告警等多维数据图表展示

实时监控

  • 开发实时监控模块，通过 WebSocket 实现设备状态、生产数据、异常警告实时推送

生产地图

  • 负责生产地图与车间分布展示，实现设备区域分布、状态高亮、异常定位

状态管理

  • 基于 Vuex 统一管理大屏全局状态
  • 实现设备数据、告警信息、生产指标等模块间数据同步与联动更新

性能优化

  • 针对大屏高频数据刷新场景进行性能优化
  • 通过节流、防抖、按需渲染、定时更新控制方案降低页面资源消耗

组件封装

  • 封装通用图表组件与业务模块：统计卡片、滚动列表、轮播告警、动态排行等

告警系统

  • 实现生产异常告警功能，支持设备异常高亮、消息滚动提醒、告警等级区分与自动轮播展示

自适应布局

  • 针对大屏多分辨率场景实现自适应布局，支持不同尺寸显示器的等比缩放与响应式展示
