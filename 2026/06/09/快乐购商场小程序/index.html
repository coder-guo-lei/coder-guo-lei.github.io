快乐购商场小程序

项目介绍

快乐购商城小程序是一款面向移动端用户的电商购物平台，集 商品浏览、搜索、购物车、订单管理、积分体系、商品收藏、在线支付、地址管理等功能于一体，支持微信小程序与 H5 多端运行。

应用技术：Taro React TypeScript Redux Toolkit WebSocket Three.js ECharts 百度地图SDK 微信支付API

我的职责

登录与鉴权

  • 实现微信一键登录与手机号快捷登录功能，结合 Token 鉴权与登录态持久化

商品浏览

  • 开发商品列表、商品详情、分类筛选、搜索推荐等核心业务模块

3D 展示

  • 基于 Three.js 实现商品 3D 展示功能，支持商品旋转、缩放与多角度预览

购物车

  • 封装购物车模块，实现商品规格选择、数量修改、失效商品处理、价格实时计算

支付体系

  • 接入微信支付能力，实现订单支付、支付结果回调、订单状态同步
  • 实现指纹支付与密码支付功能，提升支付安全

地图服务

  • 接入百度地图 SDK，实现收货地址选择、位置定位、地址解析与附近地址搜索

性能优化

  • 基于 WebP 图片格式转换与 CDN 静态资源分发策略，优化加载速度

数据埋点

  • 基于数据埋点实现用户行为采集，统计核心业务数据

状态管理

  • 使用 Redux Toolkit 管理全局状态
