## 项目介绍

校园即时通讯与兴趣社交平台是一款面向大学生群体的移动端社交应用，集 **即时通讯、兴趣社群、好友互动、动态发布、语音视频通话、活动组队**等功能于一体，支持 Android/iOS 双端运行。

**应用技术**：`React Native` `TypeScript` `Zustand` `Socket.io` `FlashList` `Reanimated` `React-Native-WebRTC` `SQLite`

---

## 我的职责

基于 React Native + TypeScript 搭建移动端社交平台：

### 即时通讯
- 基于 **Socket.io + WebSocket** 实现实时消息通信
- 支持**单聊、群聊、已读未读状态同步**等核心 IM 功能

### 弱网优化
- 设计消息断线重连机制，实现弱网环境下**自动重连、消息补发、心跳检测、连接状态恢复**

### 离线存储
- 使用 **SQLite** 实现离线聊天记录存储、本地会话缓存与消息持久化

### 消息同步
- 实现消息增量同步机制，通过时间戳与消息队列同步策略减少重复拉取

### 性能优化
- 基于 **FlashList** 优化万级聊天记录渲染性能，通过列表复用、按需渲染与分页加载提升流畅度
- 使用 **Reanimated** 实现聊天气泡动画、消息滑动交互与手势动画

### 音视频通话
- 基于 **react-native-webrtc** 实现语音通话与视频通话功能
- 支持音视频采集、通话状态同步与弱网通话优化

### 社交功能
- 开发兴趣社群与动态模块，实现动态发布、图片上传、点赞评论、话题标签与社群推荐

### 状态管理
- 基于 **Zustand** 管理全局状态，降低模块耦合度
